BUS FLEET & RUNNING BOARD MANAGER — ANDROID PHONE PACKAGE

This package turns your supplied HTML app into an installable Progressive Web App (PWA). It is not an APK.

EASIEST WAY TO USE IT ON ANDROID
1. Upload the contents of this folder (index.html, manifest.webmanifest, sw.js, and icons folder) to a web host that serves HTTPS. GitHub Pages is a free option.
2. Open the published HTTPS website in Chrome on your Android phone.
3. Open Chrome's three-dot menu and choose “Install app” or “Add to Home screen”. Follow the prompts.
4. The Fleet Control icon will appear on your phone and open in its own app-style window.

IMPORTANT DATA NOTE
Your current app stores fleet data in the browser on that device. It does not automatically sync between devices. Use Import & Backup regularly and keep a JSON backup. Clearing browser site data can remove locally stored records.

The service worker caches the app shell for later/offline opening after the first successful load, but browser storage and downloaded/imported files may behave differently offline.
